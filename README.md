# Конспекты по физике: сайт на Java

Сервер написан на чистой Java, без Maven и сторонних библиотек. Нужен **JDK 17 или новее**.
Сайт можно запускать у себя как сервер, а можно выгрузить в обычные HTML-файлы и выложить
на бесплатный хостинг (GitHub Pages).

## Запуск у себя

Открой терминал в папке проекта (там, где лежит `Main.java`) и выполни:

```
java Main.java
```

Сайт откроется по адресу http://localhost:8080. Другой порт: `java Main.java 9000`
(или переменная окружения `PORT`). Остановить сервер: `Ctrl+C`.

Перезапускать сервер после правки конспектов **не нужно**: файлы читаются при каждом
открытии страницы, достаточно обновить её в браузере.

## Структура

```
Main.java                      сервер, сборка страниц и экспорт
notes/                         конспекты, по одному .html-файлу на тему
static/style.css               оформление
static/app.js                  поиск по темам и меню на телефоне
static/img/                    сюда класть картинки для конспектов
.github/workflows/pages.yml    автопубликация на GitHub Pages
```

## Как добавить конспект

1. Скопируй `notes/_template.html` и переименуй, например, в `optics-lenses.html`.
   Имя файла (латиницей, цифры и дефисы) становится адресом страницы.
   Имя `index` занять нельзя.
2. Заполни шапку до строки `---`:
   - `title` — название темы,
   - `section` — раздел (темы с одинаковым названием раздела собираются в одну группу),
   - `order` — число для сортировки: чем меньше, тем выше в меню,
   - `summary` — подпись на карточке главной страницы,
   - `icon` — необязательно: эмодзи для этой темы (например, `icon: 🔭`). Если не указать,
     берётся иконка раздела.
3. Ниже строки `---` пиши обычный HTML. Файлы сохраняй в кодировке **UTF-8**.

Файлы, имя которых начинается с `_`, сайт пропускает, так что шаблон на сайте не появится.

## Оформление

- У каждого раздела свой цвет и иконка, они подбираются по названию раздела: механика, молекулярная
  физика, электричество и магнетизм, колебания и волны, оптика, атомная физика. Раздел с другим
  названием получает стабильный цвет и иконку 📘.
- На главной автоматически считаются темы, разделы, формулы (отдельные `\[ ... \]`) и задачи
  (блоки `class="example"`). В шапке конспекта показывается время чтения и число формул и задач.
- Заголовки `<h2>` нумеруются сами, а у блоков `formula`, `example`, `mistakes` есть цветные ярлыки.
- Цвета и размеры меняются в начале `static/style.css`. Тексты главной страницы находятся в
  `Main.java`, в функции `indexContent`.

## Формулы

Формулы рисует MathJax (подключается с CDN, нужен интернет у того, кто открывает сайт).

- в строке: `\( F = ma \)`
- отдельной строкой по центру: `\[ E = \frac{mv^2}{2} \]`

## Блоки оформления

| Класс | Для чего |
|---|---|
| `<div class="formula">` | рамка с основными формулами |
| `<div class="example">` | разобранная задача |
| `<div class="mistakes">` | частые ошибки |
| `<p class="lead">` | вступление под заголовком |

Внутри блоков можно ставить `<p class="title">` (маленький заголовок) и `<p class="what">`
(серое пояснение под формулой).

## Картинки и ссылки внутри конспектов

Картинку положи в `static/img/` и вставь в конспект так (путь всегда начинается с `/static/`):

```html
<img src="/static/img/force-diagram.png" alt="Силы, действующие на брусок">
```

Ссылка на другой конспект: `<a href="/note/newton-laws">Законы Ньютона</a>`.
При выгрузке в файлы такие ссылки пересчитываются автоматически.

## Печать и PDF

Конспект можно распечатать или сохранить в PDF из браузера (`Ctrl+P`): меню и лишние элементы
при печати скрываются.

## Выгрузка в готовые HTML-файлы

```
java Main.java export
```

Появится папка `dist` с готовым сайтом: `index.html`, по одному `.html` на каждую тему и
папка `static`. Ссылки в ней относительные, поэтому сайт работает и в подпапке адреса
(как на GitHub Pages). Папку можно загрузить на любой статический хостинг.
Если вместо русских букв на сайте «кракозябры», запускай так: `java -Dfile.encoding=UTF-8 Main.java export`
(GitHub Pages уже собирает сайт с этим флагом).
Другая папка: `java Main.java export моя-папка`. Команда не перезапишет папку с чужими файлами:
очищает она только то, что создала сама.

## Публикация на GitHub Pages

Автопубликация уже настроена в файле `.github/workflows/pages.yml`. Нужно один раз:

1. Создать на github.com **публичный** репозиторий (на бесплатном аккаунте Pages работает
   только с публичными).
2. Загрузить в него весь проект, включая скрытую папку `.github`.
3. В репозитории открыть **Settings → Pages** и в поле **Source** выбрать **GitHub Actions**.
4. Подождать 1–2 минуты (ход сборки виден на вкладке **Actions**). Сайт появится по адресу
   `https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

После этого сайт обновляется сам: изменил или добавил файл в `notes/`, отправил коммит в ветку
`main` и через минуту-две изменения на сайте. Файлы можно править прямо на сайте GitHub
(кнопка с карандашом у файла или **Add file → Create new file**).
